# Word Guess OBS — Static Edition

Сайт настройки и браузерный оверлей для игры в угадывание слов в Twitch-чате. Работает как статический сайт: **Node.js, сервер, Render и установка не нужны**.

## Публикация на GitHub Pages
1. В репозитории открой **Settings → Pages**.
2. В разделе **Build and deployment** выбери **GitHub Actions**.
3. Вкладка **Actions** → запусти workflow **Deploy static site to GitHub Pages** (или дождись автоматического запуска после push).
4. После успешного деплоя сайт будет доступен по адресу `https://ferifest.github.io/word-guess-obs/`.

## Использование
1. Открой сайт, введи логин Twitch-канала и настрой игру.
2. Сгенерируй ссылку, скопируй её.
3. В OBS добавь источник **Браузер**, вставь ссылку и выставь предложенные размеры.
4. Зрители угадывают слово обычными сообщениями в чате.

Команды в чате: `!угадай старт`, `!угадай подсказка`, `!угадай стоп`, `!угадай турнир 5`, `!угадай статус`.

## Важные ограничения статической версии
- Каждый OBS Browser Source подключается к Twitch IRC напрямую и самостоятельно ведёт раунд. Несколько оверлеев одного канала не синхронизируются друг с другом.
- Подключение анонимное и предназначено для чтения публичного чата. Twitch IRC может не передавать теги модерации анонимному клиенту, поэтому проверка команд модераторов не гарантируется. Для надёжной модераторской авторизации нужен OAuth и серверная часть.
- Список слов и логика игры находятся в браузере; это лёгкая развлекательная игра, не защищённая от просмотра ответа через DevTools.
- Пользовательские слова передаются в URL Browser Source. Не вставляй туда приватные данные.
- Сайт не отправляет сообщения в чат и не требует Twitch-пароль.
