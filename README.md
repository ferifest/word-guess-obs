# Word Guess OBS — v1.3

Компактный виджет для угадывания слов в Twitch-чате и сайт настройки OBS.

## Запуск локально
Требуется Node.js 18+.
```bash
npm install
npm start
```
Открой `http://localhost:3000/`, введи Twitch-канал, выбери тему, сложность, интервал подсказок, цвет и размеры. Скопируй выданный URL в OBS → Browser Source.

## Развёртывание
GitHub Pages не запускает Node.js и WebSocket. Для работы Twitch-чата нужен Node.js web service. Проект подготовлен для Render Blueprint через `render.yaml`:
1. Открой Render → New → Blueprint и подключи этот репозиторий.
2. Подтверди создание Web Service и Persistent Disk.
3. Задай секретную переменную `ADMIN_KEY` в Environment.
4. Оставь `DATA_DIR=/var/data`, заданный Blueprint.
5. После деплоя открой публичный адрес сервиса и настрой канал.
6. Вставь выданный HTTPS URL `/overlay.html?... ` в OBS Browser Source.

Размер по умолчанию — 1000 × 300 px. В оверлее есть автоматические подсказки, последние попытки и общий выбранный акцентный цвет.

## Команды Twitch
Стример и модераторы:
- `!угадай старт`
- `!угадай подсказка`
- `!угадай стоп`
- `!угадай турнир 5`

Все зрители:
- `!угадай статус`

Обычные сообщения чата считаются попытками угадать слово.

## Состав
- `server.js` — Node.js сервер, WebSocket и Twitch IRC.
- `public/setup.html` — сайт настройки.
- `public/overlay.html` — OBS overlay.
- `public/control.html` — расширенная панель управления.
- `render.yaml`, `Dockerfile` — варианты деплоя.
- `config.example.json`, `.env.example` — примеры конфигурации.

## Ограничения
- Один экземпляр обслуживает один Twitch-канал и одну общую игру.
- Для публичного сервера обязательно задай `ADMIN_KEY`.
- Twitch IRC подключается анонимно для чтения чата. Бот, который отправляет сообщения в чат, требует отдельной авторизации.
- Перед эфиром проверь реальное подключение Twitch и OBS на опубликованном сервисе.
